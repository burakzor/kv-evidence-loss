# Results

## `answers/{method}_{budget}.parquet`
One file per method and budget, one row per question, index `id`. The full-cache baseline is `full_1.0.parquet` (`scripts/run_full_baseline.py`); compressed runs use the same layout, e.g. `snapkv_0.2.parquet`.

| column | type | meaning |
|---|---|---|
| `id` (index) | str | HotpotQA question id |
| `method` | str | `full`, `snapkv`, `h2o`, ... |
| `budget` | float | share of the prompt's KV cache kept (1.0 = full cache) |
| `model` | str | e.g. `Qwen/Qwen3-8B` |
| `device` | str | GPU name (`NVIDIA A100-SXM4-40GB`, `mps`, ...); compare runs only within the same device |
| `question` | str | question text |
| `gold` | str | HotpotQA gold answer |
| `answer` | str | model output, stripped, stop token removed |
| `contains` | bool | normalized gold appears in normalized answer as whole words (main metric) |
| `contains_alias` | bool | `contains`, or one of the question's aliases (`data/hotpotqa/answer_aliases.csv`) appears in the answer |
| `f1` | float | token-level F1 as in the official HotpotQA script (gold only) |
| `prompt_tokens` | int | prompt length in tokens |
| `new_tokens` | int | generated tokens, stop token excluded |
| `truncated` | bool | generation hit `max_new_tokens` before the stop token |

Generation: `scripts/prompts.py` (prompt with instruction, Qwen3 chat template, thinking disabled) and `scripts/generation.py` (bfloat16, greedy, `max_new_tokens=64`). Scoring: `scripts/scoring.py`.

Any answers file can be re-scored without the model: `python scripts/rescore.py [files]` (default: every file here). Run it after the alias file changes so that all conditions use the same aliases.

## Answer aliases (`data/hotpotqa/answer_aliases.csv`)
Some gold answers are more specific than their question asks ("June 2003" for "what year"), so a correct short answer fails `contains`. Aliases are shorter forms of the gold that still fully answer the question. They are generated by `scripts/make_aliases.py` from the question and gold answer only (never from model outputs), reviewed by hand, and used identically for every condition. Rules:

| rule | alias | example |
|---|---|---|
| R1 | drop a noun the question already asks for | "43,000 marchers" (how many marchers) → "43,000" |
| R2 | year only, if the question asks for a year (not a day/date) | "June 2003" → "2003" |
| R3 | city only, for "City, Region/Country" place answers (never the region) | "Knoxville, Tennessee" → "Knoxville" |
| R4 | drop leading prepositions/hedges and "above sea level" | "from 1989 until 1994" → "1989 until 1994" |
| R5 | drop company suffixes and titles | "President Bill Clinton" → "Bill Clinton" |
| R6 | spelling only: number words ≤ 20 ↔ digits, unit abbreviations | "ten" ↔ "10", "ft" ↔ "feet" |

Never aliased: other names or synonyms, abbreviations not in the gold, partial lists, or vaguer answers. The rules were written after the manual check of `full_1.0` showed correct short answers failing `contains`; this is disclosed in the report.

## `answers/{method}_{budget}_check.csv`
Random sample (seed 0) for a manual check of the scores. `human_correct` is filled in by hand (True/False).

## `raw/`
Large outputs (kept token indices, tensors). Ignored by git.
